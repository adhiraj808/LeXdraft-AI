# Install with:  pip install -r requirements.txt -r requirements-ml.txt
# Or build the ML image:  docker build -f Dockerfile.ml -t legal-draft-ml .
#

# all-MiniLM-L6-v2 embeddings). Without it the app still drafts fully, using
# keyword classification + template/cloud-LLM generation, and the retriever
# logs one line that RAG is unavailable.
#
# Embeddings prefer ChromaDB's bundled ONNX encoder (onnxruntime, already a
# chromadb dependency) so PyTorch is NOT required. Set

# sentence-transformers backend (needs torch, see requirements-training.txt).
